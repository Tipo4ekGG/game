# Рикошет

Минималистичная чёрно-белая браузерная игра на выживание. Управляйте белой точкой и уворачивайтесь от геометрических фигур, которые отскакивают от стен и друг от друга.

## Управление

- Нажмите «Начать игру», затем нажмите на круг в центре поля.
- Перемещайте курсор. На сенсорном экране удерживайте палец на поле.
- Можно играть стрелками или WASD: первая клавиша начинает попытку.
- Escape или кнопка вверху — пауза. Для продолжения вернитесь к обозначенной точке и нажмите на неё либо используйте клавиши.
- Выход курсора за поле, отпускание пальца и переключение вкладки останавливают игру.

Результат — время выживания. Каждые 12 секунд появляется предупреждение о новой фигуре; фигура добавляется только при свободном месте вдали от игрока. Скорость постепенно растёт. Рекорд хранится локально в браузере, общей таблицы результатов нет.

## Запуск

Статический сайт без сборки и серверных зависимостей. Откройте `index.html` либо запустите любой статический HTTP-сервер из этой папки.

## GitHub Pages

В настройках репозитория: Settings → Pages → Deploy from a branch → main → / (root) → Save.
Все пути относительные, сайт работает в подпапке `/game/`.

## Устройство

- `game.js` — игровой цикл с физикой 120 Гц, ввод, отрисовка и состояния игры.
- `geometry.js` — проверка пути игрока с учётом радиуса, кругов и рёбер многоугольников.
- `vendor/matter.min.js` — Matter.js 0.20.0, MIT (лицензия в `vendor/LICENSE`), сохранён локально: внешние CDN не нужны.
- `style.css` — адаптивный монохромный интерфейс.

Перемещение курсора проверяется по всему отрезку между событиями, а не только в конечной точке. Потеря фокуса и изменение размера поля ставят игру на паузу. Учитывается системная настройка уменьшения движения: отключены след игрока и движение фоновых фигур в меню.
